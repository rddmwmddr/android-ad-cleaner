# 鸿蒙词条线索

线索不是词条，未经真机核实。手写文件，`gui/harmony_vocab.py` 只链接不渲染。

一条线索要变成词条，必须先在某台机器上实测并写进 `Recipes.ets`，再由生成器算出来。不能从这里直接抄过去。

每条四个字段：来源、日期、摘录、涉及的家族与分组。
