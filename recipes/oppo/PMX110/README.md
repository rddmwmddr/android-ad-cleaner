# OPPO Find X10 Pro Max（PMX110）

2026-11-05 社区实测逐页核对，系统为 `PMX110_17.0.0.116(CN01)`，Android 17。脚本按这个版本录制，
`BUILD` 写的是同代的 `PMX110_17.0.0`——17.0.0.x 共用这份路径，同族其他 ColorOS 17 机型也靠它当
参考脚本（#319 / #483）。**这份记录来自社区贡献者的真机，维护方没有在自己机器上复跑过。**

```bash
python3 tool/run.py -s <序列号> backup
python3 tool/run.py -s <序列号> recipe
python3 tool/run.py -s <序列号> finish
```

可只跑某一段，例如 `recipe 软件商店`。本脚本不挂起组件、不处理快应用和通知渠道、不关闭开发者模式；
这些继续走 `run.py` 的独立确认流程。

## 本版本的范围

| 分段 | 处理 | 保留与边界 |
|---|---|---|
| 广告跟踪 | 设置搜索「广告跟踪」→「限制广告跟踪」直达；列表用右上菜单「全部关闭」整表关，重开菜单看它是否置灰来确认；再显示系统应用关第二轮，事后恢复显示方式 | 仅录制型号和完整版本匹配时批量处理；参考/安全模式跳过，不重置标识符，不逐个读取或保存个人应用名单 |
| 浏览器 | 直达 `BrowserPreferencesPage`，广告管理关闭开屏、资讯列表、摇一摇广告；个性化管理关闭个性化广告推荐 | 「个性化内容推荐」部分安装版本没有这一行：有就关并回读，没有就记「未显示」；不改搜索引擎、历史、密码或书签 |
| 软件商店 | 公开 `APP_SETTINGS` 入口；关闭隐私 → 个性化推荐，以及服务管理中的点名推广位 | 普通游戏分类、客服、资产、工具、AI 搜索与安全功能保持原状；不改下载更新 |
| 下拉搜索 | `gs://search/setting`；关闭两项推荐资讯、当前显示的录制推广/热榜卡片、搜索框提示词及隐私个性化推荐 | 榜单 / 小说 / 购物等搜索数据源、消息总开关、应用建议与便捷服务都不动；未显示的卡片单独记录，不计作关闭 |
| 负一屏 | 主设置从桌面头像进入；「热点资讯」页有导出，`InfoFlowSettingActivity` 直达；轮播选择「不显示」 | 回读单选及推荐服务总开关；天气、步数与快递卡片保留。本机设置页没有找到搜索框提示词，未录入 |
| 主题 | 公开 `APP_SETTINGS` 入口；只关闭开屏广告和个性化推荐设置 | 消息通知保持原状；个性化推荐设置关完要重进隐私页再回读 |
| 视频 | 深链 `yoli://yoli.com/mine_act_lib_yoli/settings` 直达设置页，落点校验通过才进个性化管理；关闭两项个性化推荐 | 缺少应用时跳过，导航失败停止本段；不截图账号页，不改在线播放、下载与消息通知 |
| 游戏中心 | `APP_SETTINGS` 直达设置页（页上的「隐私」是分组标题、点不动），进「隐私开关设置」→「个性化推荐管理」 | 没装应用时跳过本段 |
| 小布建议 | 设置 → OPPO AI → 小布建议 → 资讯服务 | 快递、出行、日程与商圈服务不动 |

商店服务管理录制版本为 `26.7.81_CN`，主题为 `17.20.6`。

- 维护方没有 PMX110 真机，未复跑以上任何一项。

  复核，这条以社区实测为准，仍标为未由维护方复跑。

  点名关它。旧记录「点了没反应」保持原样，不当成已验证。
