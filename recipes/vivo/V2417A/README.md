### 本机差异

- 系统广告与隐私、全局搜索、阅图锁屏页面均已确认可以通过 Activity 启动，脚本使用这些入口，避开系统设置首页悬浮搜索框遮挡列表首行的问题。带 `$` 的设置 Activity 先做 shell 引用。广告与隐私页使用 `settle=0` 跳过首页消弹窗，避免将开关说明中的“关闭后”误认成关闭按钮。
- 商店设置页未导出，从商店界面进入。冷启动可能先出现“月度精品”，只点“进入首页”，不点安装。
- 商店个性化开关的标题包含“，开启/关闭”，关闭后标题会改变；本机的“确认关闭”按钮未被通用确认逻辑识别。脚本逐行处理明确的关闭确认，再按稳定标题回读。
- 服务管理页的广告悬浮项叫“悬浮球”，不是部分其他 vivo 机型的“悬浮窗”。
- 浏览器设置页未导出，`am start` 直达抛 `SecurityException: not exported from uid`，只能从界面走。入口随版本变：`31.1.3.1` 是底部“菜单 → 设置”；`31.3.0.0` 起底部标签栏改成首页/视频/AI/影视小说/我的，没有“菜单”，“设置”挂在“我的”页右上角。该图标只有 `content-desc`、没有 `text`，`texts()` 取两者之一，所以按“设置”点名能找到，不能用 `tap_icon()`——它只挑文字与描述都为空的节点。新权限申请只拒绝；需要同意协议才能进入时，本段未完成，不代用户同意。
- 负一屏设置页未导出，从桌面滑入；HOME 也可能直接恢复到上次停留的负一屏，此时核对 `HiBoard` 和“添加组件”后直接进入设置。子页之间核对实际 Activity，设置面板按单屏处理；不拨动热点资讯页的形态单选钮。

### 浏览器 31.3.0.0

2026-11-02 贡献者在同一台真机上复跑，浏览器升到 `31.3.0.0`，整段因“没找到「菜单」”未完成，本段改动就是为了这条入口差异。新首页的“首页设置”改成默认/极简/自定义三选一单选钮，“首页上滑展示资讯”只在选中极简首页之后才出现在页面上，脚本仍然先选极简首页再逐项点名；多出的“首页展示AI”不在去广告范围，没有拨动。八项处理项在新版本上全部关成，回读确认同页其他开关未变。

## 运行与单独确认的操作

```bash
python3 tool/run.py devices
python3 tool/run.py -s S check
python3 tool/run.py -s S backup
python3 tool/run.py -s S recipe
# 也可只跑一段：recipe 应用商店
python3 tool/run.py -s S finish
```

`S` 替换成自己手机的序列号。运行时保持手机解锁且空闲；手动切换应用会中断页面验证，遇到未完成段时核对原因后重跑。结束后关闭开发者模式和 USB 调试。

本机脚本不包含营销通知清单、快应用开关或包挂起。营销通知应走 `chan-scan`，由机主筛掉服务类渠道，再用 `chan-off`；本轮另用通用流程关闭了五个明确营销渠道，未将用户的第三方 App 列表写入脚本。快应用系统服务开关也已另行验证可关闭、回读及备份原值，必须征得机主同意后单独运行 `quickapp off`，恢复用 `quickapp on`。

App 内开关按上表入口手动恢复；浏览器首页的本机原值为“默认首页”。不提交 `backups/`、账号页面、通知内容或设备序列号。
