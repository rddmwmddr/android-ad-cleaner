能关掉什么

      
拨的是系统和 App 自带的开关。下拉搜索、负一屏卡片、应用商店的安装和更新、天气预警、快递提醒，这些功能保留。

    

    

      
系统广告
个性化广告、广告跟踪（OAID）、智能推荐服务。

      
热搜和资讯
下拉搜索的热榜、负一屏资讯、浏览器信息流。

      
推广位
应用商店的轮播、开屏、悬浮活动、签到福利。

      
营销推送
各 App 的「内容与营销」「活动优惠」通知。订单、物流、聊天通知保留。

      
快应用
广告链接跳进去的免安装小程序。关闭后跳转被系统拦下。

      
广告组件
OPPO 广告服务、小米系统广告组件。挂起，可以恢复。

    

  






  

    

      
怎么用

      
手机版打开点一下就行；电脑版用数据线，有机型脚本的手机从插线到完成 4 到 6 分钟。

    

    

      

        
手机版不用电脑，第一次做 3 个设置约 1 分钟

        
    
          
  1. 做 3 个设置
    打开开发者选项、无线调试，授权本 App。图文和视频教程里有每个品牌的连点位置。
    2. 
          
  2. 点「一键去广告」
    先检测手机型号和系统、扫描营销通知，扫完停在确认页。
    3. 
          
  3. 确认要关的项
    默认勾选和电脑版一致，想改就先改，点「开始」才动手。
    4. 
          
  4. 后台执行
    在一块看不见的后台屏上逐项关闭，这时可以照常用手机。不支持后台屏的机型会借用当前屏幕，那时页面会写「请不要碰手机」。
    5. 
          
  5. 完成
    每一项都成功就完成了。想恢复点「⋯」→「还原改动」，完成页也能帮你关掉开发者模式。
    6. 
        

      

      

        
电脑版数据线连电脑

        
    
          
  1. 连接手机
    打开开发者模式和 USB 调试，用数据线连电脑。客户端里有五个品牌的图文教程。
    2. 
          
  2. 检测
    读取型号、系统版本、机型脚本、快应用和广告组件的状态。只读。
    3. 
          
  3. 选择
    营销通知按渠道列出，服务类渠道默认不勾。快应用和广告组件由你决定。
    4. 
          
  4. 执行
    开始前存一份改动前的快照。执行中显示进度和日志，手机放在一边。
    5. 
          
  5. 完成
    列出每一步的结果。关闭开发者模式，改动保留。「还原改动」可以恢复。
    6.

常见问题

    

      
（电脑版）Mac 怎么看是哪种芯片？
屏幕左上角苹果图标 → 关于本机。「芯片」一栏写 Apple M 开头的是 Apple 芯片，写 Intel 的是 Intel 芯片。

      
（电脑版）Windows 弹出「Windows 已保护你的电脑」
安装程序没有代码签名。点「更多信息」→「仍要运行」。

      
（电脑版）Windows 提示缺少 WebView2，或提示「程序文件被 Windows 标记成来自网络」
到微软官网下载安装「WebView2 Evergreen Bootstrapper」，然后打开本程序。安装后提示没有消失，把弹窗括号里的原文发到反馈里。
用的是便携版（zip 解压出来的）时，提示可能不是真的缺 WebView2，而是解压出来的文件被 Windows 标成「来自网络」、加载时被拦住了：对下载的 zip 点右键 →「属性」→ 勾选「解除锁定」→ 确定，重新解压后再打开；zip 已经删了，就在解压出来的文件夹里按住 Shift 点右键 →「在此处打开 PowerShell 窗口」，粘贴 Get-ChildItem . -Recurse -File | Unblock-File 回车。安装版不受影响。
提示「本地程序集被判成远程来源」时，确认 AndroidAdCleaner.exe 旁边有 AndroidAdCleaner.exe.config（新版包自带，别删、别改名）；没有就用最新版 zip 重新解压，有了还这样也换最新版。
这几类提示弹出时，整段文字已经复制到剪贴板，可以直接粘贴到反馈里，不用手抄；剪贴板被占着时按 Ctrl+C 也能复制。

      
（电脑版）Windows 上装了新版，旧的「安卓去广告」还在，两个程序并存
国内走 Gitee 拿到的是免安装版（zip），它不会替换、也不会卸载之前装过的旧版。想让新版顶掉旧版，两种做法任选：用 GitHub 上的安装版覆盖安装，它和旧版共用同一个安装标识，会原地升级并清掉旧的开始菜单项和桌面快捷方式；或先卸载旧的「安卓去广告」（0.3.2 及更早版本装的名字）——Windows 11 在「设置 → 应用 → 已安装的应用」里，Windows 10 在「设置 → 应用和功能」里——再删掉桌面和开始菜单里的旧快捷方式。卸载只删程序目录，数据与备份保留。

      
（电脑版）插上手机，客户端认不出来
换一根能传数据的线，插电脑后面的 USB 口；后面的口是 USB 2.0 的话，换一个 USB 3.0 口再试；手机通知栏里 USB 用途选「传输文件」；手机弹窗点「允许 USB 调试」。荣耀、华为打开「仅充电模式下允许 ADB 调试」；三星装三星 USB 驱动。退出电脑上的手机助手和安卓模拟器。

      
小米 / Redmi 点不动，跑一半锁屏
开发者选项里打开「USB 调试（安全设置）」，需要插 SIM 卡、登录小米账号。

      
会影响系统更新和保修吗？
不会。不 root，不解锁，不改系统分区。用到的是开发者选项和系统自带的设置项。

      
关完还会有广告吗？
会剩一些：浏览器搜索框的轮播热词没有开关；新装的 App 带着广告跟踪和营销通知，装新 App 后再跑一次（电脑版客户端，或手机 App 的「一键去广告」）。第三方 App 自己的开屏广告不在范围内。

      
怎么恢复？
电脑版在左下角「还原改动」，手机版是右上角「⋯」→「还原改动」：恢复快应用、恢复挂起的广告组件、重新打开关掉的营销通知。App 里的开关按清单路径打开。
