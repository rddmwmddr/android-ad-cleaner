# 荣耀 / MagicOS 手动清单

实测机型：PNM-AN10（MagicOS 10），2026-10-23。机型脚本：`recipes/honor-PNM-AN10/`，重跑约 4 分钟。
补充机型：WKL-AN20（MagicOS 11.0.0.111 / Android 17），2026-10-28 逐项路径实测；[新脚本说明](../../recipes/honor-WKL-AN20/README.md)。新脚本整轮及用时尚未真机复测。
补充机型：CLE-AN00（Magic V Flip2，MagicOS 10.0.0.175 / Android 16），2026-11-07 整轮实测，下面「CLE-AN00 的差别」单列。
符号：🔴 关掉　🟢 保留　⚠️ 注意

## CLE-AN00 的差别

- 广告与隐私能直达，不用搜索：`com.hihonor.id/.oaid.ui.AdvertisingPrivacyActivity`。
- 下拉搜索能直达：`com.hihonor.search/.feature.mainpage.presentation.page.HomeActivity`。个性化管理里点名关「个性化推荐」「个性化广告」。
- 负一屏能直达：`com.hihonor.hiboard/com.hihonor.intelligent.LauncherActivity`，不用手势。
- 应用市场底部「我的」带角标，读作「我的,您在应用市场共有 N 条通知」。「热门推荐管理」是「内容推荐服务」页里的一个开关。
- 浏览器是百度版：我的 → 右上齿轮 → 搜索下一条推荐、消息设置（新闻热点、兴趣推送）。「隐私设置 → 广告设置」是网页。
- 桌面文件夹：「更多推荐」的设置页在这台上没导出，脚本没处理；要关请手动打开桌面文件夹 → 底部「更多推荐」→ 设置（路径照 PNM-AN10，本机未验证）。
- 主题：没同意用户协议时打开就弹协议，不代为同意，这一段跳过。
- 音乐：「广告推荐设置」里关「个性化广告推荐」、**打开**「减少广告」（方向相反）。
- 音乐：更多设置里的「启动后自动播放歌曲」开着时，一打开就放歌，约 1.3 秒出声。它不是广告，不替用户改；脚本发现用户原本没在听就立刻暂停。不想响那一下，手动关掉这个开关。

## 1. 系统：广告与隐私

**路径**：设置 → 搜索「广告」→ 广告与隐私

- 🔴 右上 ⋮ → 显示系统程序 → 右上 ⋮ → 全部关闭（所有 App 的广告标识读取）
- 🔴 智能推荐服务

## 2. YOYO 建议

**路径**：设置 → 搜索「新闻资讯」

- 🔴 新闻资讯

## 3. 下拉搜索

**路径**：桌面中间向下滑 → 按返回收起键盘 → 搜索框旁「更多」→ 设置

- 🔴 首页显示 → 热搜榜、热搜词推荐
- 🔴 个性化管理 → 全部关

## 4. 负一屏

**路径**：桌面从左边缘向右滑 → 头像 → 设置

- 🔴 智能推荐、个性化广告、个性化消息
- 🔴 资讯服务 → 资讯精选

## 5. 桌面文件夹推荐

「热门推荐」「精品应用」文件夹底部会推荐没装的 App。

- 🔴 打开文件夹 → 底部「更多推荐」→ 设置 → 全部关
- 🔴 「热门推荐」文件夹 → 设置 → 关闭

## 6. 应用市场

**路径**：应用市场 → 我的 → 设置

- 🔴 内容推荐服务 → 营销服务推荐、个性化服务推荐（两个分开点，连点第二个会失效）
- 🔴 消息通知管理 → 消息通知；🟢 应用更新
- 🔴 消息中心提醒 → 活动福利、游戏动态
- 🔴 服务模式 → 基本服务（首页推荐流消失，只留搜索、安装、更新）
- ⚠️ 切到基本服务后，设置入口消失。切回完整服务要重新同意协议，协议会重新打开个性化推荐。

## 7. 浏览器

**路径**：经典首页：我的 → 右上第三个图标；简洁首页：更多 → 设置

- 🔴 模式选择 → 简洁首页
- 🔴 消息通知 → 新闻热点、兴趣推送
- 🔴 隐私管理 → 个性化推荐 → 个性化内容
- 🔴 隐私管理 → 互动广告管理 → 全部关（含摇一摇）
- ⚠️ 搜索框里的热词没有开关。

## 8. 主题

**路径**：主题 → 我的 → 设置

- 🔴 通知 → 三项全关（内容推荐和活动信息）
- 🔴 个性化服务 → 全部关

## 9. 视频（优酷荣耀版）

**路径**：视频 → 设置 → 其他设置

- 🔴 个性化内容、个性化广告、OAID

## 10. 系统管家

**路径**：系统管家 → 右上齿轮

- 🔴 应用推荐
- 🟢 扩展业务里的清理、查杀、拦截

## 11. 音乐（网易云荣耀版）

**路径**：音乐 → 我的 → 右上齿轮 → 更多设置

- 🔴 消息和隐私设置 → 朋友页显示推荐动态
- 🔴 第三方推送服务开关 → 全部关（活动、中奖信息）
- 🟢 个性化服务（每日推荐、私人雷达，属于听歌功能）
- ⚠️ 抽屉菜单里不要上下翻，会误点「扫一扫」。

## 12. 阅读

**路径**：阅读 → 我的 → 更多设置

- 🔴 接收新通知
- 🔴 广告推荐服务 → 全部关
- ⚠️ 「接收新通知」每次重启 App 会自己打开。挡住推送的是它的通知渠道，见第 14 项。

## 13. 魔法画报（锁屏杂志）

**路径**：设置 → 搜索「杂志」→ 魔法画报

- 🔴 锁屏画报轮播、锁屏进入魔法画报

## 14. 营销通知

荣耀的营销渠道名叫「营销通知」，渠道 id 形如 `com.hihonor.android.pushagent.LOW.<数字>pnc`。

- 🔴 各 App 的「营销通知」，实测 26 个
- 🟢 同一个 App 的服务通知

## 15. 快应用（要 adb，要你同意）

用电脑跑：`run.py quickapp` 检测，`quickapp off` 关闭。见 [07-快应用](../07-快应用.md)。

| 包 | 作用 |
|---|---|
| `com.hihonor.quickengine` | 快应用引擎 |
| `com.hihonor.quickgame` | 快游戏 |
| `com.honor.quickgamecenter` | 快游戏中心 |

## WKL-AN20 / MagicOS 11 差异

- 系统完整版本为 `WKL-AN20 11.0.0.111(SP7C00E110R101P7)`。专用脚本限制型号和此版本，不直接沿用 PNM-AN10 的所有操作。
- 搜索「YOYO」可找到「YOYO 建议」，但本机建议列表未发现新闻资讯；不动出行服务。
- 浏览器「更多 → 设置 → 消息通知」还包含「精彩推荐」「每日推送」；与新闻热点、兴趣推送一同核对。首页按「简洁首页」单选状态确认。
- 应用市场保留原来的服务模式和安装、更新、下载设置。已有「热门推荐管理」可核对；旧版精品应用/文件夹管理的额外 Activity 不可直接启动。
- 音乐「消息和隐私设置」还包含「展示“摇一摇”类开屏广告」，并可进入「广告推荐设置 → 个性化广告推荐」。第三方推送说明包含评论提醒，应保留；听歌的个性化服务也保留。新脚本的音乐段须由机主先手动打开「更多设置」再单独运行。
- 主题从正常界面进入 `mvvm.settings.SettingsAC`，shell 直达被拒绝。只关通知页明确用于内容推荐和活动的消息通知、短信、邮件，以及个性化内容/广告。忽略屏外或不可用的确认按钮。
- 阅读只处理「广告推荐服务 → 个性化广告」，不关闭整个接收新通知开关。
- 魔法画报用设置搜索「画报」进入；轮播开关叫「锁屏壁纸轮播」，另有「锁屏进入魔法画报」「数据流量自动更新」。
- 人工处理的 13 个营销渠道回读均关闭，其余渠道和应用总开关未变。渠道 ID 和机主的应用列表不写入通用脚本。
- 已同意挂起的快应用后来曾被系统重新拉起进程。挂起状态和进程状态须分别核对，不能承诺永久停止，也不升级为卸载或停用。
