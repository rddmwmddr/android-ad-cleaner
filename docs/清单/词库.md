# 品牌词库：开关词条与同页保留项

由 `tool/vocab.py` 从机型脚本现算（`python3 tool/vocab.py > docs/清单/词库.md`），不要手改。

按家族和分组列出机型脚本点名的开关（词条）、每条要拨的方向和同页保留项，都带出处。入口怎么进看[入口速查](入口速查.md)。社区上报里还没落进脚本的叫法看[词条线索](词条线索.md)，那边的不算词条。

**用之前：** 词条说明别的机型上这个开关叫这个，不代表这台手机上它管同一件事，写脚本要真机核对。同页保留项只在那一页成立，不是品牌级的禁词表。「要开」是保护类开关：开头带否定词（`polarity.NEG_PREFIX`）且带广告词，引擎会把它拨到开，判定在 `polarity.want_state()`；不要把这类词条按普通广告开关处理。「不碰」是点了名、引擎却不会拨的行（既没否定词也没广告词），出现即说明那条点名没生效。

出处写成 `目录:行号`，指 `recipes/<目录>/recipe.py`；别的文件写全文件名。这里读 `p.off()` 和 `close_named()`：共 1165 处词，另有 21 处没有点名（整页全关，没有词）。
