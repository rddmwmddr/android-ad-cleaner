# 入口速查：广告与推荐开关在哪

由 `tool/entries.py` 生成（`python3 tool/entries.py > docs/清单/入口速查.md`），不要手改。
每个分组按快慢排三档：**直达页面**（不点菜单）→ **设置搜索**（系统设置顶部搜索框）→ **菜单路径**。
「用过的机型」从机型脚本里现算；没写机型的条目出自同品牌的手动清单。快应用按包名处理，不在这张表里。
