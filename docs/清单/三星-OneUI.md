## 通知渠道的实际结构（与国产 ROM 不同）

One UI 4 的 `AppNotificationSettings` 首层**没有**渠道列表，只有四个开关/条目：`显示通知`（应用总开关）、`提醒`、`应用程序角标`、`应用程序内通知设置`。

渠道列表在 `通知类别` 这**一整行可点击条目**后面，点进去是 `com.android.settings/.SubSettings`，标题结构与「通知类别 → 应用名 → 分组名 → 渠道名」四层。所以按国产 ROM 的「首层找渠道行」思路在三星上必然找不到。用 Edge（`com.microsoft.emmx`）做对照，结构一致，属 One UI 4 的全局行为。

两个额外注意点：

- 三星侧屏边缘有个常驻触发手柄（`resource-id=trigger_layout_container`，`content-desc=侧屏幕面板`，bounds 约 `[1384,493][1440,949]`），它只有 `content-desc` 没有 `text`，且贴在屏幕右缘。读屏时会被当成两条同名「渠道行」输出，容易和「同名 2 行」判据混淆。
- 渠道名 `mName` 是 App 创建渠道时写入的，**切换系统语言不会自动重新本地化**。同一台机器从繁体切到简体后，同一次 `dumpsys notification` 里出现繁简混排（如 `Other channel` 变为「营销和促销」，而 `com.samsung.android.spay` 仍是「行銷與促銷活動」）。按渠道名去页面上找行会因此失配。

## 本次处理结果

21 条候选渠道中，人工审定关闭 13 条纯营销渠道：10 条经读屏逐条关闭并回读确认 `mImportance=0`；3 条（Edge 的新闻快报、最近的新闻、热门文章）因 `com.microsoft.emmx allowNoti=false`——整个应用通知被禁用——系统设置不列出该分组，属等效关闭。8 条服务类与含义不明确的渠道保留未动：红包加速器、演出票务、已共享列表活动、内容推荐、重要最新资讯、信息通知（Knox 工作资料）、内容信息、通知和信息。

`quickapp` 未检测到快应用组件；`check` 未匹配到可挂起的广告包，因此本次没有挂起任何包。Google 广告设置中的「停用广告个性化」在本机原本就处于关闭（已退出个性化）状态。
