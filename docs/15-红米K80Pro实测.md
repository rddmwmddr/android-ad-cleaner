## 专用脚本入口

- 系统广告：设置 → 隐私与安全 → 上方「安全」标签 → 更多安全设置 → 广告服务 → 个性化广告推荐。
- 应用商店：我的 → 设置 → 隐私设置 → 个性化服务；通知设置 → 新手帮助（不碰推送消息、应用更新）。
- 手机管家：设置 → 隐私设置 → 个性化推荐；垃圾清理 → 推荐内容。
- 下载管理：右上齿轮 → 信息流设置 → 资源推荐、热榜推荐。
- 主题：**直达 `com.android.thememanager/.ThemeResourceProxyTabActivity`** → 我的 → 右上齿轮 → 每次联网时通知（保留自动更新）；隐私设置 → 个性化推荐。
- 浏览器：我的（本机是**顶部标签**：主页 / 视频 / AI搜索 / 免费小说 / 我的）→ 右上齿轮 → 主页设置 → 宫格位推送；搜索设置 → 显示猜你想搜模块。
- 全局搜索：设置 → 首页展示模块 → 搜索提示词、应用推荐（推荐未安装应用）、热搜榜单（推荐 + 热搜 / 生活 / 话题 / 娱乐四页）。
- 负一屏：设置 → 推荐卡片、热门活动；隐私设置 → 个性化推荐（搜索框、出行助手保留）。
- 天气和日历：天气「更多设置 → 设置 → 用户体验计划」→ 天气视频卡片、内容推广；日历「设置 → 设置 → 用户体验计划」→ 内容推广。

## 与 K70 的两处差异

1. **主题商店冷启动会跳包**。`com.miui.themestore` 拉起后会跳到 `com.android.thememanager`，`p.start()` 的前台校验判成「启动后离开前台」。改成直达 `com.android.thememanager/.ThemeResourceProxyTabActivity` 后稳定通过（与 K80 至尊版的结论一致）。
2. **浏览器设置是顶部齿轮，不是列表项**。齿轮是 `ImageView`，文字本身就是「设置」，出现在顶部右侧（本机 1080 宽的坐标约 `[922,133]-[1038,249]`）。冷启动时也有一次过渡窗，脚本里先 `am force-stop` 再直达 `BrowserActivity`，失败重试一次；齿轮用 80 毫秒短按点不动时，回退成 `input tap` 并回读是否进了 `BrowserSettingsActivity`。

## 边界

- 专用脚本的「关闭动作」在首轮已实际发生（20 项均为开 → 关并回读），本轮复跑验证的是**入口路径**和**已关闭状态下的幂等性**，没有再把开关打开做第二轮「开启 → 关闭」。
- 未验证：本轮 20 项的逐项还原。
- 本 PR 不修改引擎、通知渠道、快应用、msa 或 GUI 代码；这里的「启动后离开前台」只用 activity 直达绕开。判据本身在 #581 改了口径：读不出前台与一两帧的跳包过渡不再算离开，连续外占才停段，持续被别的 App 占住照样停（[ADR-0022](adr/0022-launch-foreground.md)）。
