# 07 快应用：检测和关闭

## 快应用是什么

快应用是手机厂商联合推出的「免安装小程序」，点一个链接就打开，不用去商店下载。OPPO、小米、vivo、荣耀、华为的国行手机都预装了快应用框架。

问题出在广告上：网页、短视频、小说 App 里的广告，常用 `hap://` 开头的链接，把你跳进一个快应用，打开「看小说」「领红包」「小游戏」这类页面。你没点「安装」，它也能打开，还能给你发推送。

## 我用不用得到它？

`quickapp` 会查系统的使用记录，告诉你近期打开过几次（测试时手动打开的链接也会算进去）。实测的一台 OPPO Find N3：两个快应用组件一直在后台运行，近期打开次数是 0。

```text
$ python3 tool/run.py -s <序列号> quickapp
检测到 2 个快应用组件：
  快应用平台      com.nearme.instant.platform        未挂起  后台在跑  近期没打开过
  快应用本地服务    com.oppo.instant.local.service     未挂起  后台在跑  近期没打开过
hap:// 链接由 com.nearme.instant.platform/.dispatch.activity.HapDispatcherActivity 接管：网页或 App 里的广告可以用这类链接跳进快应用。
关闭：python3 tool/run.py -s <序列号> quickapp off（要机主同意，可还原）
```

| 结果 | 建议 |
|---|---|
| 近期没打开过 | 关掉，对你没有影响 |
| 近期打开过 | 想一想是不是自己主动用的。如果某个常用服务（比如缴费、乘车码）是从快应用打开的，关掉后这个入口会打不开 |
| 靠它做签到、攒积分 | **别关**。关掉以后这些入口全部停在「快应用服务已关闭」的拦截页，签到会断；要恢复得走拦截页的「确认开启」或 `quickapp on` |

## 关闭和恢复

```bash
python3 tool/run.py -s <序列号> quickapp        # 检测（只读）
python3 tool/run.py -s <序列号> quickapp off    # 关闭
python3 tool/run.py -s <序列号> quickapp on     # 恢复
```

关闭后再检测：

```text
$ python3 tool/run.py -s <序列号> quickapp
检测到 2 个快应用组件：
  快应用平台      com.nearme.instant.platform        已挂起  没在跑  近期没打开过
  快应用本地服务    com.oppo.instant.local.service     已挂起  没在跑  近期没打开过
快应用已全部关闭。广告里的 hap:// 链接会弹「应用无法使用」，不会跳进快应用。恢复：quickapp on
```

广告再想跳进快应用，系统会弹出这个提示，点「确定」就回到原来的页面：

### 实测记录（OPPO Find N3 典藏版，ColorOS 16.0.5，2026-10-24）

| 步骤 | 结果 |
|---|---|
| `quickapp off` | 2 个组件挂起，用时 2.6 秒，后台进程全部退出 |
| 打开一个 `hap://` 链接 | 弹「应用无法使用」，快应用没有启动 |
| `quickapp on` | 2 个组件恢复，同一个链接拉起快应用 |
| 再次 `quickapp off` | 2 个组件挂起，链接又被拦下 |

大部分机型使用 `pm suspend`（挂起）；vivo 的系统服务开关见下节：

- 组件留在手机里，不卸载、不停用，系统更新不受影响。
- 挂起限制后续启动，但已运行的进程未必立即退出；当前源码在成功挂起后执行 `force-stop`。图标可能仍在应用抽屉，不以图标是否消失判断成功。
- `quickapp on` 一条命令恢复。挂起记录存在 `backups/<型号>-<时间>/suspended.txt`。

## vivo / iQOO 的系统服务开关

根据 [PR #20](https://github.com/rddmwmddr/android-ad-cleaner/pull/20) 的 V2547A / OriginOS 7 真机记录，`switch_quick_app_service=0` 能拦截快应用入口。当前源码仅在 vivo / iQOO 且能读到这个开关时使用它，不停用或卸载应用，不处理智慧生活等其他 `hap://` 接收者。

- `quickapp off` 先保存原值，再写入并回读确认；重复关闭不会覆盖最初原值。
- `quickapp on` 在历次备份中查找本设备的记录并还原；找不到记录时报告失败，不默认写入 `1`。
- 备份文件为 `quickapp-setting.json`，放在忽略的 `backups/` 内，含设备标识，不要公开上传。
- 客户端按实际关闭状态显示，不再把服务开关关闭误当成“未挂起、还开着”。本轮已做自动回归；0.2.0 安装包未包含此功能。

### V2547A 入口实测（OriginOS 7 / Android 17，2026-10-25）

`switch_quick_app_service` 置 `0` 后逐个入口用 `am start -W` 验证（`0` 分别由 `quickapp off` 和
`settings put` 写入，到达的状态相同，结果一致）：

| 入口 | 结果 |
|---|---|
| `hap://` 链接（`DispatcherActivity`） | `Activity: com.vivo.hybrid/.main.activity.QuickAppSwitchOpenActivity` ——「快应用服务已关闭，是否重新开启服务？」，应用没起来 |
| 桌面「快应用中心」持久化快捷方式（`action.LAUNCH` + `EXTRA_APP=com.quickapp.center`） | 同上，落在同一个拦截页 |
| 直接启动 `com.vivo.hybrid/.main.DispatcherActivity` | `Status: ok` 但 Activity 随即自行结束，焦点退回桌面，没有进入任何快应用 |
| `quickapp on` | 开关回到原值 `1`，同一链接又能拉起 |

⚠️ 关掉总开关后，桌面上那个「快应用中心」图标还在，点开会弹「快应用服务已关闭」，
要点「确认开启」才恢复。想去掉图标只能长按手动删。

带 `quickapp-setting.json` 的这版代码也在 V2547A 上整段跑过：`quickapp off` 写入 `{"original": "1"}`
并把开关置 0，`quickapp on` 还原成 1 后自动删除记录文件。

## 没有电脑怎么办

挂起要用 adb。只有手机时可以做两件事：

1. 关掉快应用的通知：设置 → 通知管理 → 搜「快应用」→ 关掉「允许通知」。
2. 跳进快应用后，从桌面长按它的图标，删除快捷方式。

这两步挡不住广告跳转，只能挡推送和桌面图标。
