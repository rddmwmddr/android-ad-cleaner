# 07 快应用：检测和关闭

## 快应用是什么

快应用是手机厂商联合推出的「免安装小程序」，点一个链接就打开，不用去商店下载。OPPO、小米、vivo、荣耀、华为的国行手机都预装了快应用框架。

问题出在广告上：网页、短视频、小说 App 里的广告，常用 `hap://` 开头的链接，把你跳进一个快应用，打开「看小说」「领红包」「小游戏」这类页面。你没点「安装」，它也能打开，还能给你发推送。

## 我用不用得到它？

`quickapp` 会查系统的使用记录，告诉你近期打开过几次（测试时手动打开的链接也会算进去）。实测的一台 OPPO Find N3：两个快应用组件一直在后台运行，近期打开次数是 0。

```text
$ python3 tool/run.py -s 7f386895 quickapp
检测到 2 个快应用组件：
  快应用平台      com.nearme.instant.platform        未挂起  后台在跑  近期没打开过
  快应用本地服务    com.oppo.instant.local.service     未挂起  后台在跑  近期没打开过
hap:// 链接由 com.nearme.instant.platform/.dispatch.activity.HapDispatcherActivity 接管：网页或 App 里的广告可以用这类链接跳进快应用。
关闭：python3 tool/run.py -s 7f386895 quickapp off（要机主同意，可还原）
```

| 结果 | 建议 |
|---|---|
| 近期没打开过 | 关掉，对你没有影响 |
| 近期打开过 | 想一想是不是自己主动用的。如果某个常用服务（比如缴费、乘车码）是从快应用打开的，关掉后这个入口会打不开 |

## 关闭和恢复

```bash
python3 tool/run.py -s <序列号> quickapp        # 检测（只读）
python3 tool/run.py -s <序列号> quickapp off    # 关闭
python3 tool/run.py -s <序列号> quickapp on     # 恢复
```

关闭后再检测：

```text
$ python3 tool/run.py -s 7f386895 quickapp
检测到 2 个快应用组件：
  快应用平台      com.nearme.instant.platform        已挂起  没在跑  近期没打开过
  快应用本地服务    com.oppo.instant.local.service     已挂起  没在跑  近期没打开过
快应用已全部关闭。广告里的 hap:// 链接会弹「应用无法使用」，不会跳进快应用。恢复：quickapp on
```

广告再想跳进快应用，系统会弹出这个提示，点「确定」就回到原来的页面：

### 实测记录（OPPO Find N3 典藏版，ColorOS 16.0.5，2026-10-24）

| 步骤 | 结果 |
|---|---|
| `quickapp off` | 2 个组件挂起，用时 2.6 秒，后台进程全部退出 |
| 打开一个 `hap://` 链接 | 弹「应用无法使用」，快应用没有启动 |
| `quickapp on` | 2 个组件恢复，同一个链接拉起快应用 |
| 再次 `quickapp off` | 2 个组件挂起，链接又被拦下 |

关闭用的是 `pm suspend`（挂起）：

- 组件留在手机里，不卸载、不停用，系统更新不受影响。
- 挂起的组件不能运行，`hap://` 链接打不开，快应用的推送也发不出来。
- `quickapp on` 一条命令恢复。挂起记录存在 `backups/<型号>-<时间>/suspended.txt`。

### vivo / iQOO：挂起不了，改总开关

vivo 把这几个接口都锁了，三条路都要 root，实测全抛 `SecurityException`：

```text
java.lang.SecurityException: Cannot suspend com.vivo.hybrid, no root permission
java.lang.SecurityException: Cannot disable com.vivo.hybrid no root permission
Failure [only root can delete system app for a particular user]
```

所以 `quickapp off` 在 vivo 上不走挂起，改成写 secure 里的总开关 `switch_quick_app_service`：

```text
$ python3 tool/run.py -s 10AG3F06Z9001GN quickapp off
  快应用总开关 switch_quick_app_service：1 → 0
快应用已关闭：hap:// 链接和快应用入口都会停在「快应用服务已关闭」页。恢复：quickapp on
```

### 实测记录（vivo X300 Ultra / V2547A，OriginOS 7，Android 17，2026-10-25）

开关从 1 改成 0 之后，逐个入口试：

| 入口 | 结果 |
|---|---|
| `hap://` 链接（`DispatcherActivity`） | 停 `QuickAppSwitchOpenActivity`：「快应用服务已关闭，是否重新开启服务？」，应用没起来 |
| 桌面「快应用中心」持久化快捷方式（`action.LAUNCH` + `EXTRA_APP=com.quickapp.center`） | 同上 |
| 快应用管理 → 点某个快应用 | 打开的是它的设置页（存储/通知/删除），不是应用本身 |
| `quickapp on` | 开关回到 1，同一链接又能拉起 |

三点要注意：

- **不要动 `com.vivo.vhome`**（智慧生活）。它也注册了 `hap://` 的 Dispatcher，但那是智能家居遥控器，
  和快应用无关，关掉空调遥控那些会坏。
- 关掉总开关后，桌面上那个「快应用中心」图标还在，点开会弹「快应用服务已关闭」，
  要点「确认开启」才恢复。想去掉图标只能长按手动删。
- 原值记在 `backups/<型号>-<时间>/quickapp.txt`，`quickapp on` 按它还原。

## 没有电脑怎么办

挂起要用 adb。只有手机时可以做两件事：

1. 关掉快应用的通知：设置 → 通知管理 → 搜「快应用」→ 关掉「允许通知」。
2. 跳进快应用后，从桌面长按它的图标，删除快捷方式。

这两步挡不住广告跳转，只能挡推送和桌面图标。
